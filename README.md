# AdventureWorks2019 SQL Data Analysis

This project contains SQL queries executed on the **AdventureWorks2019** database to analyze employee, product, and sales-related data.  
It demonstrates strong SQL skills including joins, grouping, aggregation, and filtering.

---

## 📊 Tools Used
- Microsoft SQL Server
- AdventureWorks2019 Sample Database
- SSMS (SQL Server Management Studio)

---

## 🧠 Key Analysis Performed

| Query Focus | Skills Demonstrated |
|------------|------------------|
| Employee names, email, job titles | Joins, string functions |
| Count of products | Aggregation |
| Total sales per customer | Group By, SUM |
| Average list price | Aggregation (AVG) |
| Avg/Min/Max price per category | Multi-level joins |
| Departments with >10 employees | HAVING clause |
| Products never sold | LEFT JOIN, NULL filtering |
| Employees hired in 2019 | Date filtering |
| Customer names uppercase | String formatting |
| Sales order + Salesperson | Multiple table joins |
| Unique product sales by employees | Subqueries |
| Avg salary per department | COALESCE usage |
