📌 AdventureWorks2019 SQL Analysis

This project contains SQL queries written for the AdventureWorks2019 sample database provided by Microsoft.
It includes real-world business analysis scenarios across sales, products, customers, and employees.

🛠 Tools Used

SQL Server Management Studio (SSMS)

AdventureWorks2019 Database

🔍 Key Analysis Topics
Business Area	Insights Extracted
Employee Data	Job titles, hiring trends, salary by department
Customer Sales	Total revenue per customer, salesperson mapping
Products	Price analysis, inventory performance, never-sold products
Departments	Workforce strength and pay statistics
📑 List of Queries Included
#	Analysis Description
1	Employee names, job titles & email addresses
2	Total number of products
3	Total sales per customer
4	Average list price of products
5	Avg/Min/Max list price by product category
6	Departments with more than 10 employees
7	Products never sold
8	Employees hired in the year 2019
9	Customer names in uppercase
10	Sales order details with product & salesperson
11	Employees selling unique products
12	Average salary per department (including empty)
📌 How to Use

Download the SQL file

Restore AdventureWorks2019 database in SSMS

Run queries section-by-section to explore insights
